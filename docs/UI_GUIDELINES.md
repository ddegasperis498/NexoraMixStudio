# Linee guida UI V8

- Font base Windows: 14 px.
- Pulsanti principali: altezza minima 44 px su tablet, 36–42 px su desktop.
- Nessun testo essenziale sotto 12 px.
- Funzioni separate per scheda: Console, 4 Deck, Libreria, Mashup, Tablet, Import, MIDI.
- Trasporto sempre visibile.
- Loop, Hot Cue, Effetti e Mixer raggruppati in pannelli distinti.
- Stato Sync/Master con testo e colore, non soltanto colore.
- Proprietà readonly WPF con `Mode=OneWay`.
- Controlli touch con spaziatura sufficiente.
- Layout tablet ottimizzato per orientamento landscape.
- Modalità 2 Deck per semplicità; 4 Deck per performance avanzata; Mixer dedicato.
