# Importazione musica

## Cartella controllata

```text
%LOCALAPPDATA%\NexoraMix\Music\Inbox
```

`FileSystemWatcher` rileva la creazione o rinomina dei file. L'importazione attende brevemente che la copia sia terminata prima di aggiungere la traccia alla libreria.

## Link YouTube

Il software valida domini `youtube.com` e `youtu.be` e apre il link nel browser. Non scarica, converte o registra il flusso.

## Spotify

Spotify è utilizzato per metadati e riferimenti esterni. Waveform, BPM, Sync, effetti e mix richiedono un file locale collegato.
