# MIDI mapping

## Generic MIDI 4 Deck

| Messaggio | Comando |
|---|---|
| Note 36/37 | Play/Cue Deck A |
| Note 38/39 | Play/Cue Deck B |
| Note 40/41 | Play/Cue Deck C |
| Note 42/43 | Play/Cue Deck D |
| Note 44-47 | Sync Deck A-D |
| Note 48-51 | Master Deck A-D |
| Note 52 | Auto Mashup |
| Note 53 | Stop tutto |
| Note 54 | Registrazione master |
| CC 16-19 | Volume Deck A-D |
| CC 20 | Crossfader |
| CC 21 | Master gain |
| Pitch Bend canali 1-4 | Tempo Deck A-D |

## Stato

Il profilo Generic MIDI e verificato dai controller model tests. I profili Pioneer/AlphaTheta, Gemini, Denon, Numark, Hercules, Reloop, Traktor Kontrol e Roland restano sperimentali finche non vengono provati su hardware reale.
