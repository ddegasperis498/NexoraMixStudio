# Spotify: limiti e comportamento

Spotify viene usato esclusivamente per autenticazione e metadati di tracce, album e playlist. Il programma non scarica, registra, decodifica né miscela il flusso audio Spotify.

Flusso corretto:
1. Importa la scaletta Spotify.
2. Seleziona un riferimento.
3. Premi `COLLEGA FILE LOCALE`.
4. Scegli la copia audio che possiedi o sei autorizzato a usare.
5. Il file viene analizzato e diventa caricabile nei deck.
