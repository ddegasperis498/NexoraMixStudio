# Guida utente rapida

## Primo avvio

1. Apri `NexoraMixStudio.sln`.
2. Avvia `NexoraMix.App`.
3. Importa due file audio.
4. Carica un file nel Deck A e uno nel Deck B.
5. Imposta il master e usa Sync sul follower.

## Tablet

1. Apri **Tablet / Android**.
2. Avvia la console.
3. Apri l'indirizzo dal tablet.
4. Inserisci il codice.
5. Usa la modalità 2 Deck per una console semplice o 4 Deck per il controllo completo.

## Piatti

- Il marker ruota quando il deck è in esecuzione.
- Trascina il piatto per nudge/seek.
- Il clock audio rimane sul PC.

## Loop

Seleziona 1, 2, 4, 8, 16 o 32 battute e premi Loop On/Off.

## Effetti

Regola Filter, Echo, Crush, Saturation, Gate, Compressor, Roll e Brake.

## Musica

Copia i file autorizzati in `%LOCALAPPDATA%\NexoraMix\Music\Inbox` oppure usa Importa File.
